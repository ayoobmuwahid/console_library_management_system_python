# console_library_management_system_python

Core Requirements
Each book should contain:
ID (a unique integer)
Title
Author
Category
Total Copies
Available Copies
The application should allow the user to:
1. Add a book - Enter the details of a new book.
2. View all books - Display books with their IDs, titles, authors, and available copies.
3. Search for a book - Find a book by ID or by part of its title (case-insensitive).
4. Update book details - Change a book's title, author, or category.
5. Remove a book - Delete a book by ID.
6. Borrow a book - Decrease available copies by one. Do not allow borrowing when no copies are available.
7. Return a book - Increase available copies by one. Do not allow returns that would exceed total copies.
8. Filter by category - Display books belonging to a selected category.
9. Show unavailable books - List books with zero available copies.
10. Show a summary - Display the total number of book titles, total copies, and available copies.
Provide a simple numbered menu that repeats until the user chooses to exit
